## Architecture facts
- 4 LLM stages as ADK `Agent`s in a `SequentialAgent` (`app/agent.py`):
  outline → writer → reviewer → finalizer; state via `output_key` →
  `{placeholder}`: `chapter_outline` → `chapter_draft` → `chapter_review` →
  `chapter_final`.
- Reviewer *rewrites* rather than critiques ("Output the COMPLETE revised chapter…
  Do NOT output review notes").
- Agents have **no tools**; pure text transformers. All I/O is imperative in
  `run_book.py` (hand-rolled per-chapter loop, not ADK `LoopAgent`): fresh
  `InMemorySessionService` session per chapter, per-chapter retry (default 3) with
  `asyncio.wait_for` timeout (default 1800 s), `.progress.json` resume, per-chapter
  git commit+push (3 attempts with `pull --rebase`), graceful fallback that walks
  `chapter_final → … → chapter_outline` for best available text.
- Stage selection via `PIPELINE_AGENTS` env var read at import time; `run_book.py`
  must set env before `from app.agent import chapter_pipeline`.
- Models: local **Ollama** only via LiteLLM (`ollama_chat/<name>`, hardcoded
  `http://localhost:11434`); default `gemma4:31b`; temperature 0.7, `num_ctx`
  32768 default, `repeat_penalty` 1.2, optional `--no-think`.
- Publisher (5th, non-LLM stage, `app/tools.py:368-486`): Markdown →
  `markdown` (extra/toc/codehilite) → `$…$`/`$$…$$` → MathML via `latex2mathml`
  (silent fallback to literal) → title page + dotted-leader ToC with CSS
  `target-counter` → Pygments → **WeasyPrint** A4 PDF, auto-versioned `{slug}-vN.pdf`.
- Input: TOC as JSON/YAML/numbered text, local path or GitHub blob URL (cloned
  via SSH). 23-language support with a forceful language instruction block.
- Code size: `run_book.py` 671 L, `app/agent.py` 196 L, `app/tools.py` 486 L,
  `app/fast_api_app.py` 35 L → 1,388 L total (`wc -l`).
- Deps (`pyproject.toml`): google-adk[extensions] ≥1.15,<2; litellm ≥1.50; pyyaml;
  python-slugify; markdown ≥3.6; weasyprint ≥62; latex2mathml ≥3.77. Python ≥3.11,<3.14.
- No tests exist (`tests/unit/` holds only an empty `__init__.py`).
