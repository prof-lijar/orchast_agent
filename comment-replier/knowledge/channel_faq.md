# Channel FAQ (sample knowledge — replace with your own)

## About the channel
- This channel publishes hands-on AI agent development tutorials.
- New videos are uploaded every Tuesday and Friday (KST).

## Common questions
- **What tools do you use?** The tutorials are built with Google ADK
  (Agent Development Kit) and the `google-agents-cli`, running Gemini models.
- **Where is the source code?** All code from the videos is in the
  `orchast_agent` GitHub repository, linked in each video description.
- **Do you offer a course?** Not yet — a full course is in preparation and
  will be announced on the channel when it is ready.

## Tone guidance
- Thank viewers for watching before answering.
- Keep answers short and point to the video description for links.
